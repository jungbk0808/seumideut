# [26.08.25] 로컬 우선 데스크톱 메모 앱 MVP 와이어프레임 (개인 프로젝트)

## 개요

본 와이어프레임은 로컬 우선 데스크톱 메모 앱 MVP의 최종 선택안 기준 화면 구조를 정의한다.

핵심 방향은 다음과 같다.

- 기본 진입 화면은 작은 위젯형 빠른 메모 창으로 한다.
- 위젯 안에는 최근 메모 목록을 넣지 않는다.
- 탐색, 검색, 목록 관리는 전체 메모 관리 화면에서 처리한다.
- 글자수 카운터는 위젯과 전체 메모 화면 모두에 제공한다.
- MVP는 가벼운 작성 경험과 데스크톱 접근성을 우선한다.

---

# 화면 1. 위젯형 빠른 메모

## 화면 목적

사용자가 데스크톱 작업 중 작은 창을 띄워두고 앱 전환 부담 없이 바로 메모를 작성할 수 있게 한다.

## 공통 요구사항

- 작은 위젯형 창
- 상단 고정
- 새 메모 생성
- 제목/본문 입력
- 자동 저장 상태
- 공백 포함/공백 제외 글자수
- 전체 메모 관리 화면 진입
- 삭제 확인

## 컨셉

위젯 창은 "지금 쓰는 메모"에만 집중한다. 메모 탐색과 검색은 전체 메모 관리 화면으로 넘기고, 위젯에서는 작성, 저장 상태 확인, 글자수 확인, 상단 고정, 새 메모 생성만 제공한다.

## 핵심 UX 방향

- 작은 창 안에서는 작성에만 집중
- 탐색과 검색은 전체 메모 화면에서 처리
- 데스크톱 위에 계속 띄워두기 좋은 밀도 유지
- 글자수 정보는 편집을 방해하지 않는 하단 보조 정보로 표시

## Wireframe

```text
┌──────────────────────────────────────────┐
│  Memo                          [📌] [＋] │
├──────────────────────────────────────────┤
│ 지금 떠오른 아이디어                      │
│ ──────────────────────────────────────── │
│ 작업하다가 떠오른 내용을                   │
│ 앱 전환 없이 바로 적는다.                  │
│                                          │
│                                          │
│                                          │
│                                          │
│                                          │
│                                          │
│ 저장됨              공백 포함 42자 · 제외 31자 │
├──────────────────────────────────────────┤
│ [전체 메모 열기]                   [삭제]  │
└──────────────────────────────────────────┘
```

## 주요 요소

| 요소 | 설명 |
|---|---|
| 창 제목 | 앱 이름 또는 현재 모드 표시 |
| 핀 버튼 | 상단 고정 On/Off |
| 새 메모 버튼 | 현재 입력 흐름에서 새 메모 생성 |
| 제목 영역 | 선택된 메모 제목 입력 |
| 본문 영역 | 선택된 메모 본문 입력 |
| 저장 상태 | 저장 중/저장됨/저장 실패 표시 |
| 글자수 카운터 | 공백 포함/공백 제외 글자수 실시간 표시 |
| 전체 메모 열기 | 전체 메모 관리 화면으로 이동 |
| 삭제 버튼 | 현재 메모 삭제 확인 모달 호출 |

## 특징

- 기본 진입 화면 자체가 위젯형 빠른 메모다.
- 최근 메모 목록을 제거해 작은 창의 복잡도를 낮춘다.
- 위젯은 한 번에 하나의 메모 작성에 집중한다.
- 전체 탐색은 별도 관리 화면으로 분리한다.

## 장점

- 제품 정체성이 명확하다.
- 데스크톱 작업 흐름에 잘 붙는다.
- MVP 구현 범위가 선명하다.
- 작은 창에서도 글쓰기 공간을 충분히 확보할 수 있다.

## 단점

- 다른 메모로 전환하려면 전체 메모 화면을 열어야 한다.
- 위젯만으로는 검색이나 목록 탐색이 불가능하다.

# 화면 2. 전체 메모 관리 화면

## 화면 목적

저장된 메모를 검색, 탐색, 선택, 편집, 삭제할 수 있게 한다.

## 공통 요구사항

- 검색
- 최근 수정순 목록
- 선택한 메모 편집
- 자동 저장 상태
- 글자수 카운터
- 새 메모 생성
- 위젯으로 돌아가기
- 삭제 확인

## 컨셉

전체 메모 관리 화면은 왼쪽 목록, 오른쪽 편집 영역으로 구성된 안정적인 2-pane 데스크톱 구조를 사용한다. 위젯에서 제거한 검색과 목록 탐색 기능은 이 화면에서 처리한다.

## 핵심 UX 방향

- 메모 탐색과 편집을 동시에 제공
- 검색 결과를 목록에 즉시 반영
- 선택한 메모를 오른쪽에서 바로 수정
- 위젯으로 쉽게 돌아갈 수 있는 진입점 제공

## Wireframe

```text
┌────────────────────────────────────────────────────────────────────┐
│  전체 메모                                 [위젯으로] [항상 위] [＋] │
├──────────────────────┬─────────────────────────────────────────────┤
│ 🔍 메모 검색           │ 제목 입력                                    │
│ ┌──────────────────┐ │ ┌─────────────────────────────────────────┐ │
│ │ 검색어 입력       │ │ │ 오늘 회의 메모                           │ │
│ └──────────────────┘ │ └─────────────────────────────────────────┘ │
│                      │                                             │
│ 최근 수정순           │ 본문                                        │
│ ┌──────────────────┐ │ ┌─────────────────────────────────────────┐ │
│ │ 오늘 회의 메모    │ │ │ - MVP는 1~2주 안에                       │ │
│ │ 방금 전           │ │ │ - 글자수 카운터 필수                      │ │
│ └──────────────────┘ │ │ - 상단 고정 먼저 구현                     │ │
│ ┌──────────────────┐ │ │                                         │ │
│ │ 블로그 초안       │ │ │                                         │ │
│ │ 어제              │ │ │                                         │ │
│ └──────────────────┘ │ └─────────────────────────────────────────┘ │
│ ┌──────────────────┐ │                                             │
│ │ 할 일             │ │ 저장됨                         공백 포함 43자 │
│ │ 2일 전            │ │                              공백 제외 31자 │
│ └──────────────────┘ │                                             │
│                      │                         [삭제]              │
└──────────────────────┴─────────────────────────────────────────────┘
```

## 주요 요소

| 요소 | 설명 |
|---|---|
| 검색창 | 제목/본문 기준 검색 |
| 메모 목록 | 최근 수정순으로 메모 표시 |
| 메모 카드 | 제목, 수정 시각, 필요 시 본문 일부 표시 |
| 편집 제목 | 선택한 메모 제목 수정 |
| 편집 본문 | 선택한 메모 본문 수정 |
| 저장 상태 | 저장 중/저장됨/저장 실패 표시 |
| 글자수 카운터 | 공백 포함/공백 제외 글자수 실시간 표시 |
| 위젯으로 | 위젯형 빠른 메모 화면으로 돌아감 |
| 항상 위 | 전체 메모 화면의 상단 고정 On/Off |
| 새 메모 | 새 메모 생성 |
| 삭제 | 선택한 메모 삭제 확인 모달 호출 |

## 특징

- 전체 메모 화면은 목록, 검색, 편집을 모두 담당한다.
- `위젯으로` 버튼으로 다시 작은 메모 창으로 돌아간다.
- 위젯에서는 제거한 탐색 기능을 이 화면에서 처리한다.

## 장점

- 역할 분리가 명확하다.
- 위젯이 복잡해지지 않는다.
- 메모가 많아졌을 때 확장 가능하다.

## 단점

- 위젯만으로는 메모 전환이 불가능하다.
- 전체 화면을 여는 행동이 한 번 더 필요하다.

# 삭제 확인 모달

## 화면 목적

사용자가 실수로 메모를 삭제하지 않도록 최종 확인을 제공한다.

## Wireframe

```text
┌──────────────────────────────┐
│ 메모를 삭제할까요?             │
├──────────────────────────────┤
│ 삭제하면 목록에서 사라져요.      │
│ MVP에서는 복구를 지원하지 않을 수 │
│ 있어요.                        │
├──────────────────────────────┤
│              [취소] [삭제]     │
└──────────────────────────────┘
```

## 정책

- 삭제 버튼 클릭 시 즉시 삭제하지 않고 확인 모달을 띄운다.
- 취소 선택 시 기존 편집 화면으로 돌아간다.
- 삭제 선택 시 메모 목록에서 제거한다.
- MVP에서는 복구 기능을 제공하지 않을 수 있다.

# Error 상태

## 저장 실패

```text
┌──────────────────────────────────────────┐
│  Memo                          [📌] [＋] │
├──────────────────────────────────────────┤
│ 지금 떠오른 아이디어                      │
│ ──────────────────────────────────────── │
│ 작업하다가 떠오른 내용을                   │
│ 앱 전환 없이 바로 적는다.                  │
│                                          │
│                                          │
│ 저장 실패 · 재시도   공백 포함 42자 · 제외 31자 │
├──────────────────────────────────────────┤
│ [전체 메모 열기]                   [삭제]  │
└──────────────────────────────────────────┘
```

## 정책

- 저장 실패 시 하단 상태 텍스트를 `저장 실패 · 재시도`로 변경한다.
- 사용자가 `재시도`를 누르면 마지막 입력 내용을 다시 저장한다.
- 저장 실패 중에도 입력 내용은 화면에서 유지한다.

# 상태 정의

| 상태 | 화면 처리 |
|---|---|
| Default | 마지막으로 열었던 메모를 위젯 창에 표시 |
| Empty | 위젯에는 즉시 입력 가능한 빈 메모 표시 |
| Saving | 하단에 `저장 중...` 표시 |
| Saved | 하단에 `저장됨 · 공백 포함 N자 · 제외 N자` 표시 |
| Save Failed | 하단에 `저장 실패 · 재시도` 표시 |
| Pinned | 핀 버튼 활성화, 창이 항상 위에 유지 |
| Unpinned | 일반 창처럼 동작 |
| Full View | 전체 메모 관리 화면 표시 |
| Search Empty | 왼쪽 목록에 `검색 결과가 없어요` 표시 |
| Long Text | 본문은 스크롤, 하단 상태/글자수는 고정 |

# 주요 인터랙션

## 앱 실행

```text
앱 실행
 → 마지막으로 열었던 메모 확인
 → 있으면 위젯형 빠른 메모에 표시
 → 없으면 Empty 위젯 표시
```

## 새 메모 생성

```text
[＋] 클릭
 → 빈 메모 생성
 → 제목 또는 본문 입력 가능
 → 입력 시작 후 자동 저장
```

## 자동 저장

```text
사용자 입력
 → 하단 상태 `저장 중...`
 → 마지막 입력 후 300~800ms debounce
 → 로컬 저장 성공
 → 하단 상태 `저장됨`
```

## 글자수 계산

```text
본문 입력
 → 공백 포함 글자수 계산
 → 공백 제외 글자수 계산
 → 하단 오른쪽에 실시간 표시
```

계산 기준:

- 공백 포함: 스페이스, 탭, 줄바꿈 포함
- 공백 제외: 스페이스, 탭, 줄바꿈 제외

## 전체 메모 열기

```text
[전체 메모 열기] 클릭
 → 전체 메모 관리 화면 표시
 → 현재 메모가 선택된 상태로 유지
```

## 위젯으로 돌아가기

```text
[위젯으로] 클릭
 → 전체 메모 관리 화면 닫기 또는 축소
 → 현재 선택된 메모를 위젯형 빠른 메모에 표시
```

## 삭제

```text
[삭제] 클릭
 → 삭제 확인 모달 표시
 → [취소] 선택 시 닫기
 → [삭제] 선택 시 메모 삭제
 → 다음 최근 메모 또는 Empty 상태 표시
```

# MVP 최종 구조

1. 위젯형 빠른 메모를 기본 진입 화면으로 사용한다.
2. 위젯 안에는 최근 메모 목록을 넣지 않는다.
3. `전체 메모 열기`를 누르면 2-pane 전체 메모 관리 화면으로 이동한다.
4. 전체 메모 화면에서 검색, 목록, 선택, 편집을 처리한다.
5. 글자수 카운터는 위젯과 전체 메모 화면 모두 오른쪽 아래에 표시한다.
6. 상단 고정은 위젯 화면에서 우선 제공하고, 전체 메모 화면에도 제공 가능하다.
